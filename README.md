# 🌌 Cosmic Math — Simple Card Game

[![Live Demo](https://img.shields.io/badge/Live-Demo-blueviolet)](https://ahmed-rehmat-khan.github.io/Cosmic_Math_Simple_Card_Game/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A **premium**, self-contained cosmic-themed math card matching game built with pure HTML, CSS, and JavaScript. No build step, no dependencies — just open and play.

## ✨ Features

- 🎴 Cosmic-themed card matching gameplay
- 🌗 Light & dark theme support (auto + manual)
- 📱 Fully responsive — works on mobile, tablet, and desktop
- ⚡ Zero dependencies, single-file bundle
- 🎨 Polished UI with smooth animations and safe-area insets
- ♿ Accessible markup and keyboard-friendly interactions

## 🚀 Play

**Live:** https://ahmed-rehmat-khan.github.io/Cosmic_Math_Simple_Card_Game/

**Local:**
1. Clone the repo:
   ```bash
   git clone https://github.com/ahmed-rehmat-khan/Cosmic_Math_Simple_Card_Game.git
   ```
2. Open `index.html` in your browser.
